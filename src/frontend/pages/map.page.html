Ram Pump System Layout Terrain-aware preliminary hydraulic ram-pump planning
Analyzing terrain0%

Point A = water source. Point B = service area / reservoir. ABEARC searches surrounding lower terrain for practical ram-pump sites, routes a descending drive pipe, then evaluates the delivery pipe and preliminary hydraulic performance.

Selected distance measurement Point A = water source → Point B = service area / reservoir
Design inputs Terrain, source-flow and pipe assumptions used in the preliminary calculation
Without a desired delivery-flow target, enter the measured available source flow. Default: 12 L/min.
Straight preferred is recommended for ram-pump drive pipes. On-ground mode requires the terrain route itself to descend continuously.
Peace Corps / Warwick S-2 reference: recommended rigid drive-pipe length is 150D–1000D. ABEARC can insert a standpipe or drive tank when the source-to-pump run exceeds Lmax.
Automatic pipe sizing and ram-pump performance are preliminary engineering estimates. Gilman model data are stored locally as a dated catalog snapshot; final design must use surveyed elevations, dependable source-flow measurements and verified manufacturer performance data.
